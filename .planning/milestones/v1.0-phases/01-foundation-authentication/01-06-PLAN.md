# Plan 01-06: Handle OAuthError in Callback (GAP-04)

<objective>
Catch `OAuthError` exceptions in the `/api/auth/callback` endpoint so that CSRF state mismatches, expired OAuth state, or denied consent produce a clean redirect to the landing page with an error parameter instead of a raw 500 error. This is a security/UX hardening fix (GAP-04).
</objective>

<action>
Edit `backend/app/routers/auth.py` to handle `OAuthError`:

1. Add import at the top of the file:
   ```python
   from authlib.integrations.base_client.errors import OAuthError
   ```

2. Wrap the body of the `callback` function in a try/except block. The `authorize_access_token` call is the one that raises `OAuthError` on CSRF state mismatch or expired state.

Replace the callback function with:

```python
@router.get("/callback")
async def callback(request: Request, db: AsyncSession = Depends(get_db)):
    """Handle Google OAuth callback, upsert user, redirect with JWT."""
    try:
        token = await oauth.google.authorize_access_token(request)
    except OAuthError as e:
        error_params = urlencode({"error": "auth_failed", "detail": str(e)})
        return RedirectResponse(url=f"{settings.FRONTEND_URL}/?{error_params}")

    userinfo = token.get("userinfo")
    if not userinfo:
        return RedirectResponse(url=f"{settings.FRONTEND_URL}/?error=auth_failed")

    google_id = userinfo["sub"]
    email = userinfo["email"]
    display_name = userinfo.get("name", email)
    avatar_url = userinfo.get("picture")

    # Upsert user
    result = await db.execute(select(User).where(User.google_id == google_id))
    user = result.scalar_one_or_none()

    if user:
        user.email = email
        user.display_name = display_name
        user.avatar_url = avatar_url
    else:
        user = User(
            google_id=google_id,
            email=email,
            display_name=display_name,
            avatar_url=avatar_url,
        )
        db.add(user)

    await db.flush()
    await db.refresh(user)

    # Create JWT and redirect to frontend with token in query param
    jwt_token = create_access_token(user.id)
    params = urlencode({"token": jwt_token})
    return RedirectResponse(url=f"{settings.FRONTEND_URL}/auth/callback?{params}")
```

The key change is wrapping `authorize_access_token` in try/except and redirecting to the landing page with an error parameter on failure, instead of letting the exception propagate as a 500.
