<objective>
Deliver UI-03: get the recipient page to show the personalized page (LCP) and become
interactive within 3 seconds on a throttled mobile connection, via two load optimizations.

(a) **Route code-split** `App.jsx` with `React.lazy` + a single `<Suspense fallback={<LoadingSpinner/>}>`
so the recipient at `/i/:code` never downloads the Dashboard, Create, or AuthCallback JS —
targeting the measured 148 kB gzip main bundle every visitor (including the recipient) currently
pays for (D-07b). Motion is NOT deferred: the No-button dodge uses it immediately, so it stays
statically imported and rides the recipient's own chunks (D-08).

(b) **Recipient photo placeholder polish**: a skeleton placeholder + fade-in over a FIXED
`aspect-[4/3]` box in `InvitationReveal` to kill layout shift (CLS), plus a high-priority fetch
hint on the LCP photo `<img>` and on the existing `new Image()` preload in `InvitationGatePage`
(D-07a). The backend already serves the photo as WebP ~100–200 KB (D-09) — acceptance-check only,
no code.

Purpose: ROADMAP Phase 5 success criterion 4 — "invitation page loads in under 3 seconds on a
throttled mobile connection." The recipient flow is the emotional peak and is most likely opened
on a phone, so trimming its JS payload and eliminating photo layout shift are the highest-value
levers.
Output: `App.jsx` route-level code-splitting (lazy wrappers + Suspense); a skeleton/fade photo
placeholder over the fixed aspect-ratio box in `InvitationReveal`; a high-priority fetch hint on
the recipient photo. No new files, no new dependencies.

Decisions implemented here: D-07a (photo skeleton/placeholder + fade over fixed aspect-ratio box),
D-07b (route code-split via React.lazy + Suspense), D-08 (Motion not deferred), D-09 (WebP
acceptance-check, no code), D-10 (<3s = LCP + interactive under Fast 3G, measured manually in UAT).
Sibling plans: 05-01 -> UI-02 (bilingual toggle), 05-02 -> UI-01 (responsive). This plan edits
`InvitationReveal.jsx` and `InvitationGatePage.jsx` AFTER 05-02's responsive class edits — layer on
top, do not revert them.
</objective>
