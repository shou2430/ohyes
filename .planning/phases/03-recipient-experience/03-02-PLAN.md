<objective>
Build the complete recipient experience as a multi-screen flow within InvitationGatePage: password gate with shake error animation, invitation reveal with photo/title/Yes/No buttons, escalating No button dodge behavior with sparkle trails and dodge counter, message input card, and postcard keepsake with optional image download — all connected by slide transitions using Motion.

Component implementation:
```jsx
import { useState } from "react";
import { useTranslation } from "react-i18next";
import { motion } from "motion/react";

const API_URL = import.meta.env.VITE_API_URL || "";

export default function PasswordGate({ title, shortCode, onVerified }) {
  const { t } = useTranslation();
  const [password, setPassword] = useState("");
  const [error, setError] = useState(false);
  const [loading, setLoading] = useState(false);
  const [shakeKey, setShakeKey] = useState(0);

  const handleSubmit = async (e) => {
    e.preventDefault();
    if (!password.trim() || loading) return;

    setLoading(true);
    setError(false);

    try {
      const res = await fetch(
        `${API_URL}/api/invitations/by-code/${shortCode}/verify`,
        {
          method: "POST",
          headers: { "Content-Type": "application/json" },
          body: JSON.stringify({ password }),
        }
      );

      if (res.ok) {
        const data = await res.json();
        onVerified(data);
      } else {
        setError(true);
        setShakeKey((k) => k + 1);
      }
    } catch {
      setError(true);
      setShakeKey((k) => k + 1);
    } finally {
      setLoading(false);
    }
  };

  return (
    <div className="flex min-h-screen items-center justify-center bg-cream px-4">
      <div className="w-full max-w-[360px] text-center">
        <h1 className="text-2xl font-semibold text-text-primary line-clamp-2">
          {title}
        </h1>
        <p className="mt-3 text-base text-text-secondary">
          {t("recipient.passwordInstruction")}
        </p>
        <form onSubmit={handleSubmit}>
          <motion.div
            key={shakeKey}
            animate={
              error
                ? { x: [0, -8, 8, -6, 6, -3, 3, 0] }
                : { x: 0 }
            }
            transition={
              error
                ? { type: "spring", stiffness: 600, damping: 15, mass: 0.5 }
                : {}
            }
          >
            <input
              type="password"
              value={password}
              onChange={(e) => {
                setPassword(e.target.value);
                if (error) setError(false);
              }}
              placeholder={t("recipient.passwordPlaceholder")}
              className={`mt-6 h-11 w-full rounded-lg border px-4 text-center text-base tracking-widest text-text-primary outline-none transition-colors placeholder:tracking-normal placeholder:text-text-secondary ${
                error
                  ? "border-destructive focus:border-destructive focus:ring-1 focus:ring-destructive"
                  : "border-border focus:border-accent focus:ring-1 focus:ring-accent"
              }`}
              aria-label={t("recipient.passwordPlaceholder")}
            />
          </motion.div>
          {error && (
            <p className="mt-2 text-sm text-destructive" aria-live="assertive">
              {t("recipient.wrongPassword")}
            </p>
          )}
          <button
            type="submit"
            disabled={!password.trim() || loading}
            className="mt-4 h-11 w-full rounded-lg bg-accent text-sm font-semibold text-white transition-transform hover:scale-[1.02] disabled:cursor-not-allowed disabled:opacity-50"
            aria-label={t("recipient.unlock")}
          >
            {loading ? "..." : t("recipient.unlock")}
          </button>
        </form>
      </div>
    </div>
  );
}
```

<action>
Create `frontend/src/components/recipient/NoButton.jsx`:

Props: `{ onDodge, dodgeCount }` where `onDodge` is called after each dodge to increment the parent's counter.

The component manages its own position state and dodge mechanics. Key implementation:

1. **Stage determination** from `dodgeCount`:
   - 0-2: Stage 1 (Shy) — stiffness 200, damping 20, distance 60-80px
   - 3-5: Stage 2 (Nervous) — stiffness 350, damping 15, distance 100-140px
   - 6-9: Stage 3 (Frantic) — stiffness 500, damping 12, distance 160-200px
   - 10-14: Stage 4 (Panicked) — stiffness 700, damping 10, distance 200-260px
   - 15+: Stage 5 (Desperate) — stiffness 900, damping 8, random teleport in viewport

2. **Dodge vector calculation:**
   - Get pointer position from event (`clientX`, `clientY`; for touch use `touches[0]`)
   - Get button center from `getBoundingClientRect()`
   - Compute escape direction: `buttonCenter - pointerPosition` (normalized)
   - Multiply by random distance within stage range
   - Add random angular offset +/-30 degrees via rotation matrix
   - Clamp to viewport bounds with 16px padding
   - For stage 5: ignore escape vector, pick random x,y within viewport bounds

3. **Mobile detection:** `const isMobile = window.matchMedia('(pointer: coarse)').matches || 'ontouchstart' in window;`

4. **Mobile transition:** Use `type: "tween", duration: 0.15` instead of spring.

5. **Ghost click prevention:** After each dodge, set a `pointerEvents: "none"` state for 150ms.

6. **Wobble (stages 4-5):** After landing, animate `rotate: [0, deg, -deg, deg/2, -deg/2, 0]` with duration 0.5s. Stage 4: deg=3. Stage 5: deg=5.

7. **Stage 5 button text:** Cycle through `["noWait", "noPlease", "noGiveUp", "noFine"]` using `(dodgeCount - 15) % 4`.

8. **isDodging state:** Starts false (button is in inline flow). On first dodge, set true and switch to `position: absolute`.

9. **Scale effect (stage 3+):** Apply `scale: 0.95` briefly on each dodge.

export function spawnSparkles(oldX, oldY, newX, newY, stage) {
  const counts = [0, 0, 4, 7, 10, 14]; // per stage index (0-indexed, stage 1 = index 0)
  const count = counts[Math.min(stage, 5)] || 0;
  if (count === 0) return [];

  const particles = [];
  for (let i = 0; i < count; i++) {
    const t = Math.random();
    const x = oldX + (newX - oldX) * t + (Math.random() - 0.5) * 40;
    const y = oldY + (newY - oldY) * t + (Math.random() - 0.5) * 40;
    const size = 6 + Math.random() * 8; // 6-14px
    const color = Math.random() < 0.6 ? "#FBBF24" : "#FFFFFF";
    particles.push({ id: `${Date.now()}-${i}-${Math.random()}`, x, y, size, color });
  }
  return particles;
}
