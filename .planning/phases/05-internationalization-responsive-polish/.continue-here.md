## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| "No button won't dodge on hover" false alarm | In DevTools device toolbar (375px = touch emulation) the No button only dodges on tap, not hover. This is CORRECT: touch has no hover, so only `onTouchStart` fires. It dodges on desktop hover (`onHoverStart`). NOT a Phase 5 change (NoButton untouched since Phase 3, commit 3dfbce6). | advisory | Don't file this as a bug. To test hover-dodge, turn OFF the device toolbar (Ctrl+Shift+M) and hover with a real mouse. |
| opus subagents time out on the company gateway | ~76 tok/s gateway; opus Agent spawns time out; sonnet returns full results but can occasionally return empty while files land. | advisory | Use sonnet for executor/verifier/reviewer (config model_profile=adaptive resolves this). ALWAYS spot-check files + git commits before judging success — do not trust empty agent returns. |
| Local UAT stack is ephemeral | backend/dev/preview/postgres run as session background processes and DIE when the session ends. | advisory | Restart them on resume (see Infrastructure State below) before continuing UAT. |
