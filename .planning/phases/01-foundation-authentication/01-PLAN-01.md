# Plan 1-01: Backend Scaffolding — FastAPI, DB Models, Alembic, Health Endpoint

<objective>
Scaffold the FastAPI backend with uv, create the User SQLAlchemy model, configure async database connectivity, initialize Alembic for migrations, and expose a /api/health endpoint. This establishes the backend foundation that all subsequent plans build upon.
</objective>

<threat_model>
| ID | Threat | Severity | ASVS | Mitigation | Task |
|----|--------|----------|------|------------|------|
| T-1-01 | Database credentials leaked in source code | high | V2.10 | All secrets loaded from environment variables via pydantic-settings; .env in .gitignore; .env.example has placeholder values only | 1-01-02 |
| T-1-02 | SQL injection via raw queries | medium | V5.3 | All queries use SQLAlchemy ORM (parameterized); no raw SQL strings | 1-01-04 |
</threat_model>

<context>
- D-10: Monorepo with /frontend and /backend top-level directories
- D-12: uv for Python dependency management, FastAPI, SQLAlchemy 2.0 async, asyncpg, Alembic
- D-13: Ruff for backend linting + formatting
- Research: DATABASE_URL from Railway uses postgresql:// but asyncpg needs postgresql+asyncpg:// — transform at runtime
- Research: Alembic must use async template; model modules must be imported in env.py to avoid empty migrations
- Research: Use pool_size=5, max_overflow=10 per CLAUDE.md recommendation
</context>

```python
    GOOGLE_CLIENT_SECRET: str = ""

    SESSION_SECRET: str = "change-me-in-production"

    API_URL: str = "http://localhost:8000"

    # Storage

        return self.DATABASE_URL.replace(
```

Create `backend/app/core/database.py`:
```python
from collections.abc import AsyncGenerator

from sqlalchemy.ext.asyncio import (
    AsyncSession,
    async_sessionmaker,
    create_async_engine,
)

from app.core.config import settings

engine = create_async_engine(
    settings.async_database_url,
    pool_size=5,
    max_overflow=10,
    echo=False,
)

async_session_factory = async_sessionmaker(
    engine,
    class_=AsyncSession,
    expire_on_commit=False,
)


async def get_db() -> AsyncGenerator[AsyncSession, None]:
    """FastAPI dependency that yields an async database session."""
    async with async_session_factory() as session:
        try:
            yield session
            await session.commit()
        except Exception:
            await session.rollback()
            raise
```

```python
from fastapi import APIRouter
from sqlalchemy import text

from app.core.database import engine

router = APIRouter(prefix="/api", tags=["health"])


@router.get("/health")
async def health_check():
    """Health check endpoint that verifies database connectivity."""
    try:
        async with engine.connect() as conn:
            await conn.execute(text("SELECT 1"))
        return {"status": "healthy", "database": "connected"}
    except Exception:
        return {"status": "unhealthy", "database": "disconnected"}
```

Create `backend/app/main.py`:
```python
from fastapi import FastAPI

from app.routers.health import router as health_router

app = FastAPI(title="OhYes API", version="0.1.0")

app.include_router(health_router)


@app.get("/")
async def root():
    return {"message": "OhYes API"}
```
